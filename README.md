## กระบวนการทำความสะอาดข้อมูล (Data Cleaning)

เพื่อรับประกันคุณภาพของชุดข้อมูล ได้ดำเนินกระบวนการทำความสะอาดตามเกณฑ์ของอาจารย์ดังนี้:
1. **การตรวจสอบและตัดบทความซ้ำซ้อน (Deduplication):** บทความ 1 เรื่องถูกกำหนดให้อยู่ในสาขาที่เหมาะสมเพียงสาขาเดียว หากพบบทความปรากฏซ้ำข้ามสาขา (เช่น ปรากฏทั้งใน AI และ Software) ระบบจะทำการตัดรายการซ้ำออก (ตัดออก 178 รายการ)
2. **การกรองภาษาต่างประเทศ (Language Filter):** กรองบทความที่ระบุภาษาอื่นที่ไม่ใช่ภาษาอังกฤษออก เพื่อให้สอดคล้องกับโมเดลภาษาที่ใช้ (ตัดออก 25 รายการ)
3. **การคัดกรองบทความที่ขาดบทคัดย่อ (Missing Abstracts):** คัดกรองบทความที่ไม่มี Abstract หรือมีข้อความสั้นกว่าเกณฑ์มาตรฐาน (ตัดออก 30 รายการ)
4. **การตรวจค้นและขจัดบทความนอกศาสตร์ (Domain Leakage):** ขจัดบทความที่ติดคำค้นหลุดเข้ามาในหมวดคอมพิวเตอร์ เช่น ดัชนีราคาอสังหาริมทรัพย์ในดูไบ, ประสิทธิผลการจัดการโรงแรมและการท่องเที่ยว, การประเมินรากฟันเทียม, และการประเมินผลผลิตข้าวสาลี (ตัดออก 59 รายการ)

## การแสดงผลด้วยภาพแบบโต้ตอบ (Interactive Visualizations)

แดชบอร์ดถูกออกแบบให้ทำงานบนเบราว์เซอร์ได้ทันทีโดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอก ประกอบด้วย 5 มุมมองหลัก:
1. **Keyword Co-occurrence Network:** กราฟเครือข่ายความสัมพันธ์คำสำคัญ ขนาดโหนดแทน Document Frequency ความหนาของเส้นแทน Co-occurrence Weight พร้อมระบบจัดกลุ่ม 5 Thematic Clusters, ระบบซูม/เลื่อน และคลิกโหนดเพื่อดูบทความจริง
2. **Interactive Keyword Word Cloud:** คลาวด์คำสำคัญเชิงโต้ตอบที่สามารถปรับเลือกดูตามปีที่ตีพิมพ์ (2020–2026) เพื่อติดตามการเปลี่ยนแปลงของคำศัพท์สำคัญ
3. **Cross-Subject Topic Overlap Heatmap:** แผนภูมิความร้อนแสดงการปรากฏของคำสำคัญยอดนิยมในแต่ละสาขาวิชา สะท้อนการประยุกต์ใช้ AI และ Deep Learning ข้ามศาสตร์
4. **Strategic Topic Growth Quadrant:** จตุภาควิเคราะห์การเติบโตเชิงยุทธศาสตร์ เปรียบเทียบอัตราการเติบโต ($log_2(Recent/Prior)$) เทียบกับปริมาณบทความ ช่วยแยกแยะหัวข้อเกิดใหม่ (Emerging Topics) และหัวข้อหลัก (Established Topics)
5. **Scopus Document Explorer:** ระบบสืบค้นและสำรวจบทความวิจัย ค้นหาตามชื่อเรื่อง ผู้แต่ง คำสำคัญ และสาขาวิชา พร้อมเปิดดูบทคัดย่อและลิงก์ DOI

## การเตรียมคุณลักษณะข้อความ (Feature Vector & Text Embedding)

1. **การรวมฟิลด์ข้อความ:** บูรณาการ Title, Abstract, Author Keywords และ Index Keywords โดยมีแท็กระบุนำหน้าชัดเจน
2. **ข้อจำกัดความยาวโทเค็น (512 Tokens):** รองรับโมเดลเฉพาะทางด้านวิทยาศาสตร์ SPECTER2 (`allenai/specter2_base` + proximity adapter) ซึ่งข้อมูลส่วนใหญ่มีความยาวเฉลี่ย 318 โทเค็น
3. **L2 Normalization:** ปรับขนาดเวกเตอร์ 768 มิติ ให้มีความยาวเท่ากับ 1 หน่วย ช่วยให้การวัด Cosine Similarity ผ่าน Dot Product ทำได้อย่างรวดเร็วและมีประสิทธิภาพ
4. **Machine Learning Readiness:** ข้อมูลพร้อมนำไปประยุกต์ใช้งานในโจทย์ Subject Classification, Semantic Clustering (K-Means / HDBSCAN) และ Paper Recommendation
